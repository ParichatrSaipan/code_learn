# react
1. create react app with express backend
```bash
cd react_1
npm create vite@latest my-app # create react app with vite
cd react_1 # go back to root directory
npm install # install express
cls # clear terminal
```

2. run express server
```bash 
npm run dev # run express server
```

more
```bash
cls # clear terminal
cd.. # go back to root directory
```
